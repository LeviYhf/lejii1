# ScholarAthlete OLED — De La Salle HS

Static web app package for GitHub Pages.

## Publish on GitHub Pages
1. Upload the files in this folder to the **root** of your GitHub repository.
2. Keep `index.html` at the root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for the deployment to finish and open the Pages URL shown in Settings → Pages.

The app uses external Tailwind CSS, Lucide icons, and Google Fonts, so those visual assets need an internet connection. App data stored in local browser storage stays on that device/browser unless the app is connected to a backend.
